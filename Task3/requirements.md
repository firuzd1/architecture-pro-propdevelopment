# Требования к внешним интеграциям — умный домофон и шлагбаум

## 1. Требования к безопасности

- Биометрические данные (лица, номера авто) являются особой категорией персональных данных по 152-ФЗ — необходимо отдельное согласие от каждого собственника
- Биометрия не должна храниться на серверах партнёра дольше времени необходимого для распознавания
- Данные одного жилого комплекса не должны быть доступны партнёру другого жилого комплекса
- Все запросы к платформе партнёра должны проходить через API Gateway — прямых вызовов из мобильного приложения быть не должно
- Трафик между системами только по HTTPS/TLS 1.2 и выше
- Логирование всех событий доступа (кто, когда, к какому объекту)
- При утечке биометрических данных уведомить пользователей и регулятора в течение 72 часов

## 2. Протоколы аутентификации и авторизации

- Аутентификация партнёра — OAuth 2.0 с client credentials flow
- Каждый запрос от мобильного приложения содержит JWT токен пользователя
- API Gateway проверяет токен и добавляет идентификатор собственника и ЖК в запрос к партнёру
- Партнёр не получает напрямую токены пользователей — только данные которые ему нужны
- Разграничение прав: партнёр одного ЖК не может запросить данные другого ЖК
- Ротация ключей доступа не реже одного раза в 90 дней

## 3. Взаимодействие между системами

- Все запросы от мобильного приложения идут через API Gateway
- API Gateway авторизует запрос, добавляет контекст (id собственника, id ЖК) и проксирует к платформе партнёра
- Платформа партнёра возвращает события (звонок, распознавание, открытие) в tenant-core-app через webhook
- tenant-core-app сохраняет историю событий доступа
- Мобильное приложение получает push-уведомления о событиях через платформу партнёра
- Контракт API с партнёром должен быть согласован со специалистом по ИБ до интеграции
- Регулярный аудит контракта API партнёра — не реже одного раза в год
